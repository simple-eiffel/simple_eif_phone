SIMPLE_EIF_PHONE

The app's one handle on the phone. Eiffel owns the loop: `wait_for_event' / `poll_event' deliver `last_event', and before they return, `lifecycle' and `touches' have already applied it. There are no callbacks into Eiffel: the C glue queues, Eiffel pulls. One handle per process; when the app's root returns, the glue finishes the activity and ends the process (research D-012).

Constants

Back_system: INTEGER = 0

Android also handles Back (finishes the app); the key is still delivered.

Back_app: INTEGER = 1

Back is consumed; only the app reacts.

Events

wait_for_event

Block until an event arrives; it becomes `last_event'.

Requires

not_destroyed: not lifecycle.is_destroyed no_open_frame: not screen.in_frame

Ensures

delivered: not last_event.is_none counted: delivery_count = old delivery_count + 1 fresh_event: last_event /= old last_event kind_from_c: last_event.kind = c_cur_kind lifecycle_in_step: lifecycle.last_applied = last_event touches_in_step: touches.last_applied = last_event metrics_refreshed: is_metric_kind (last_event.kind) implies (metrics.width = screen.width and metrics.height = screen.height) drops_monotonic: dropped_event_count >= old dropped_event_count

poll_event (a_timeout_ms: INTEGER)

Wait at most `a_timeout_ms'; `last_event' is none on timeout.

Requires

timeout_ok: a_timeout_ms >= 0 not_destroyed: not lifecycle.is_destroyed no_open_frame: not screen.in_frame

Ensures

counted_when_delivered: not last_event.is_none implies delivery_count = old delivery_count + 1 nothing_taken_on_timeout: last_event.is_none implies delivery_count = old delivery_count kind_from_c: not last_event.is_none implies last_event.kind = c_cur_kind lifecycle_in_step: not last_event.is_none implies lifecycle.last_applied = last_event touches_in_step: not last_event.is_none implies touches.last_applied = last_event metrics_refreshed: is_metric_kind (last_event.kind) implies (metrics.width = screen.width and metrics.height = screen.height) timeout_changes_nothing: last_event.is_none implies (lifecycle.last_applied = old lifecycle.last_applied and touches.last_applied = old touches.last_applied) drops_monotonic: dropped_event_count >= old dropped_event_count

PHONE_CONTROLS

Android's own controls, for Eiffel: `phone.controls'. Build controls, give the top one to `show', and pass each event to `dispatch' (or let SIMPLE_EIF_PHONE.run_controls do that). Needs `controls = true' in eifphone.toml. Nothing here waits for Android. Orders go out through `port'; what the user does comes back as events, and `dispatch' turns those into calls of the agents the app gave its controls, on the app's own thread.

Access

port: PHONE_CONTROL_PORT

root: detachable PHONE_CONTROL

The control filling the screen.

item (a_id: INTEGER): detachable PHONE_CONTROL

The control with id `a_id'.

count: INTEGER

Controls made so far.

on_back: detachable PROCEDURE [TUPLE]

What the Back key does, if not Android's default.

is_available: BOOLEAN

Was this app built with `controls = true'?

Commands

show (a_root: PHONE_CONTROL)

Fill the screen with `a_root', in place of what was there.

Requires

mine: a_root.controls = Current

Ensures

shown: root = a_root

toast (a_text: READABLE_STRING_32)

A brief message at the bottom of the screen.

Requires

text_given: not a_text.is_empty

confirm (a_title, a_message, a_yes, a_no: READABLE_STRING_32; a_answer: PROCEDURE [TUPLE [BOOLEAN]])

Ask a question. `a_answer' gets True for `a_yes'; False for `a_no' or when the user backs out. An empty `a_no' leaves one button.

Requires

yes_given: not a_yes.is_empty

pick_date (a_year, a_month, a_day: INTEGER; a_answer: PROCEDURE [TUPLE [READABLE_STRING_32]])

Android's date picker, opened at the date given. `a_answer' gets "year-month-day", or empty text when the user backs out.

Requires

month_valid: a_month >= 1 and a_month <= 12 day_valid: a_day >= 1 and a_day <= 31

pick_time (a_hour, a_minute: INTEGER; a_answer: PROCEDURE [TUPLE [READABLE_STRING_32]])

Android's time picker. `a_answer' gets "hour:minute", or empty text when the user backs out.

Requires

hour_valid: a_hour >= 0 and a_hour <= 23 minute_valid: a_minute >= 0 and a_minute <= 59

set_on_back (a_action: PROCEDURE [TUPLE])

From now on the Back key calls `a_action' and leaves the app alone.

Ensures

set: on_back = a_action

clear_on_back

From now on Back does what Android does: it closes the app.

Ensures

cleared: on_back = Void

Paint the canvases that asked for it. Call when no event is waiting.

dispatch (a_event: PHONE_EVENT)

Hand `a_event' to its control. Anything else is ignored.

Invariant

count_non_negative: count >= 0 ids_ahead: last_id >= count

PHONE_CONTROL

One of Android's controls. The classes that inherit this cover the common ones. Any other works through this class itself: create l_stars.make_any (phone.controls, "android.widget.RatingBar") l_stars.call_integer ("setNumStars", 5) l_stars.listen ("setOnRatingBarChangeListener", agent on_rating) l_stars.ask ("getRating", agent on_answer) Any public method taking nothing, a whole number, a true/false or a text can be called by name, and any setOn...Listener can be listened to.
