Use a control that has no class

Any control with a public constructor taking a Context works by name. The rating bar here has no class of its own.

create l_stars.make_any (phone.controls, "android.widget.RatingBar")
l_stars.call_integer ("setNumStars", 5)
l_stars.listen ("setOnRatingBarChangeListener", agent on_stars)
l_stars.ask ("getRating", agent on_rating)
l_stars.set_on_failure (agent on_refused)

A wrong class or method name is reported to on_failure. It does not stop the app.

Show a list of any length

Rows are asked for as they come into view, so 31,000 rows cost no more than 100.

create l_list.make (phone.controls)
l_list.set_row_text (agent verse_text)
l_list.set_row_count (31000)
l_list.set_on_select (agent on_verse)

Draw with a finger

A canvas paints through Android's own Canvas: smooth lines, and text in any script. Ask for a repaint rather than painting from each point, and one frame covers them all.

canvas.set_on_paint (agent paint)
canvas.set_on_sweep (agent on_sweep)

on_sweep (a_x, a_y: REAL_64)
	do
		points.extend ([a_x, a_y])
		canvas.request_repaint
	end

Keep frames coming while fingers move

A busy touch screen can fill the queue faster than you drain it. Take events up to a limit, then show a frame.

from until phone.lifecycle.is_destroyed loop
	phone.wait_for_event
	handle
	from
		l_more := True
		l_taken := 1
	until
		not l_more or l_taken >= Events_per_frame or phone.lifecycle.is_destroyed
	loop
		phone.poll_event (0)
		if phone.last_event.is_none then
			l_more := False
		else
			handle
			l_taken := l_taken + 1
		end
	end
	if dirty and not phone.lifecycle.is_destroyed then
		show
	end
end

Track each finger

inspect phone.last_event.kind
when Kind_touch_down then
	start_stroke (phone.last_event)     -- by phone.last_event.pointer_id
when Kind_touch_move then
	continue_stroke (phone.last_event)  -- phone.last_event.x, .y
when Kind_touch_up then
	finish_stroke (phone.last_event)
when Kind_touch_cancel, Kind_focus_lost, Kind_window_lost then
	forget_all_strokes
else
end

Always handle Kind_touch_cancel: Android can take a touch back.

Draw your own pixels

Keep an ARGB32 image in a MANAGED_POINTER, then copy it to the screen in one call.

if phone.screen.has_window then
	phone.screen.begin_frame
	if phone.screen.in_frame then
		phone.screen.present_argb (l_pixels.item, l_width, l_height, l_width * 4)
		phone.screen.end_frame
	end
end

Stay ready for in_frame to be False: Android may refuse a frame.

Save state when paused

Android can end a paused app without warning, so save then.

when Kind_paused then
	save_strokes
save_path: STRING
	do
		Result := phone.storage.internal_path + "/strokes.txt"
	end

When reading the file back, guard the loop. read_line requires file_readable, which is False on an empty file.

from until f.end_of_file or else not f.file_readable loop
	f.read_line
	-- use f.last_string
end

Fit any screen

l_brush := phone.metrics.dp (6).max (2)        -- 6 dp in pixels
l_top := phone.metrics.inset_top               -- clear of the status bar
l_bottom := phone.metrics.height - phone.metrics.inset_bottom

Rebuild your image on Kind_window_resized and Kind_content_rect_changed. Only redraw everything when the size really changed.

Read text aloud

phone.speech.start                       -- once, when the app begins
...
when Kind_speech_ready then
	phone.speech.speak (l_words, "en-US")
when Kind_speech_done then
	-- finished, or stopped: see phone.last_event.service_code
when Kind_speech_failed then
	-- phone.speech.last_failure says why

Use "he-IL" for Hebrew, if the phone's engine has it. Keep each call under 4,000 characters. examples/read_aloud shows the whole thing.

Keep data in SQLite

simple_sql runs on the phone, full-text search included. Add it to your ECF, then add this to eifphone.toml:

[native]
sources = ["$SIMPLE_EIFFEL/eiffel_sqlite_2025/Clib/sqlite3.c", "$SIMPLE_EIFFEL/eiffel_sqlite_2025/Clib/esqlite.c"]
include = ["$SIMPLE_EIFFEL/eiffel_sqlite_2025/Clib"]
defines = ["SQLITE_THREADSAFE=1", "SQLITE_ENABLE_FTS5", "SQLITE_ENABLE_RTREE", "SQLITE_ENABLE_GEOPOLY", "SQLITE_ENABLE_MATH_FUNCTIONS", "SQLITE_OMIT_LOAD_EXTENSION", "SQLITE_ENABLE_COLUMN_METADATA", "SQLITE_TEMP_STORE=3"]

Keep the file in the app's own folder:

create l_db.make (phone.storage.internal_path + "/notes.db")
l_db.execute ("CREATE TABLE IF NOT EXISTS notes (id INTEGER PRIMARY KEY, body TEXT)")
l_db.execute ("INSERT INTO notes (body) VALUES ('first note')")
l_rows := l_db.query ("SELECT body FROM notes")
l_db.close

execute takes UTF-8. For text beyond ASCII, convert it first with {UTF_CONVERTER}.utf_32_string_to_utf_8_string_8. examples/touch_pad saves its strokes this way.

Write a line to the log

phone.log.set_tag ("MyApp")
phone.log.info ("loaded " + strokes.count.out + " strokes")

A tag holds at most 23 characters. Read the lines with eifphone log myapp.
